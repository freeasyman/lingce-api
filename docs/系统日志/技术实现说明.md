### 字段
- `id`
- `tenant_id`
- `tenant_name`
- `actor_id`
- `actor_name`
- `actor_role_code`
- `actor_role_name`
- `log_type`
- `action_code`
- `action_name`
- `route_path`
- `result`
- `error_message`
- `object_type`
- `object_id`
- `object_name`
- `request_summary`
- `before_summary`
- `after_summary`
- `ip_address`
- `user_agent`
- `device_type`
- `trace_id`
- `request_id`
- `created_at`

### 索引
- `created_at desc`
- `tenant_id, created_at desc`
- `actor_id, created_at desc`
- `action_code, created_at desc`
- `log_type, result, created_at desc`

## 2. 动作字典
首批建议：
- `institution_login`
- `page_enter`
- `employee_create`
- `employee_update`
- `employee_delete`
- `role_create`
- `role_update`
- `role_delete`
- `permission_update`
- `content_create`
- `content_update`
- `content_publish`
- `recording_upload`
- `recording_update`
- `recording_delete` 仅 Ops 端保留，暂不接入 inst 端

## 3. 埋点入口
### 登录
- `POST /api/v1/auth/login/institution`
- 由 auth handler 直接写库
- 登录失败也写一条

### 机构端人工操作
- 由机构端业务接口在关键动作完成后调用
- 支持匿名登录失败事件
- 支持已登录事件自动补齐 actor / tenant 快照
