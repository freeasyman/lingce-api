# 系统日志产品文档

## 1. 背景
机构端需要记录人工登录、关键页面进入、关键业务操作，供平台运营侧和客服侧查看分析。

## 2. 目标
- 记录机构端人工行为日志
- 运营端提供查询、筛选、详情查看
- 支持登录失败、登录成功、页面进入、关键操作
- 保留完整明细，不做归档/清理/导出

## 3. 范围
### 机构端记录
- 登录
- 关键页面进入
- 人工触发的关键操作

### 暂不记录
- Worker 自动任务
- Ops 端配置操作
- 录音删除（当前仅 Ops 端开放）

## 4. 日志对象
每次行为一条日志。

### 必填字段
- 机构
- 账号
- 时间
- 动作
- 类型
- 操作结果
- IP
- 设备

### 明细字段
- 角色快照
- 路由
- 对象类型/对象 ID/对象名称
- 请求摘要
- 前后摘要
- 错误信息
- Trace ID / Request ID

## 5. 行为字典
建议首批：
- `login`
- `page_view`
- `create`
- `update`
- `delete`
- `approve`
- `publish`
- `upload`
- `import`
- `export`

可扩展具体动作码，例如：
- `institution_login`
- `page_enter`
- `employee_create`
- `role_update`
- `permission_update`
- `content_create`
- `recording_upload`
- `recording_delete`

## 6. 查询能力
运营端支持按以下条件筛选：
- 机构
- 账号
- 时间范围
- 动作
- 类型
- 结果
- IP
- 设备
- 关键词

## 7. 展示规则
- 列表默认显示一行摘要
- 进入详情查看完整字段
- 列表支持分页

## 8. 保留策略
- 永久保留
- 暂不做归档、清理、导出
