# 纯录音就诊切分项目页面任务单

## 原则

- 先复用现有录音库和运行审计。
- 只新增最小的就诊列表和就诊详情。
- 不做全量菜单重构。

## 1. 医生录音列表

### 目标

- 作为重新切分入口。

### 必做

- 每条长录音增加 `重新切分` 按钮。
- 点击后直接触发现有分析链路。
- 任务完成后显示跳转到运行审计或就诊列表的入口。

### 不做

- 不改成完整 encounter 列表。
- 不重做筛选体系。

## 2. 就诊列表

### 目标

- 展示切分后的 `encounter` 结果。

### 必做

- 列表展示 `就诊基本信息`。
- 支持按录音、时间、状态、置信度查看。
- 支持进入详情。

### 最小字段

- 就诊 ID
- 录音 ID
- 员工名
- 起止时间
- 时长
- 摘要
- 置信度
- 状态

## 3. 就诊详情

### 目标

- 只展示基础信息和结果来源。

### 必做

- 基本信息卡片。
- 对应录音信息。
- 切分片段。
- 转写摘要。
- 置信度与状态。

### 不做

- 不做复杂编辑流。
- 不做完整病历页。

## 4. 运行审计

### 目标

- 复用现有分析运行页。

### 必做

- 从录音列表和就诊详情可跳转。
- 能看到 run、step、trace、pipeline。

### 不做

- 不新增重复审计页。

## 5. 页面流转

1. 医生录音列表点 `重新切分`
2. 跳到或轮询 `运行审计`
3. 分析完成后进入 `就诊列表`
4. 点开 `就诊详情`

## 6. MVP 验收

- 录音能发起切分。
- 切分结果能落到就诊列表。
- 就诊详情能查看基础信息。
- 整条链路不依赖前端直连模型。
