# 纯录音就诊切分项目接口清单

## 1. 现成可复用

### 录音入口

- `GET /api/v1/recordings`
- `GET /api/v1/recordings/{id}`
- `GET /api/v1/recordings/{id}/play-url`
- `POST /api/v1/recordings/{id}/actions/reanalyze`
- `POST /api/v1/recordings/{id}/actions/analyze`
- `POST /api/v1/recordings/{id}/actions/transcribe`
- `POST /api/v1/recordings/{id}/actions/clean`
- `GET /api/v1/recordings/{id}/analysis`
- `POST /api/v1/recordings/{id}/analysis/feedback`

### 分析运行

- `GET /api/v1/analysis/runs`
- `GET /api/v1/analysis/runs/{id}`
- `GET /api/v1/analysis/runs/{id}/steps`
- `GET /api/v1/analysis/routes`
- `GET /api/v1/analysis/routes/{id}`

### 用途

- 录音列表发起单条重新切分。
- 运行审计查看每次执行记录。
- 详情页查看运行过程和错误。

## 2. MVP 需要新增

### 就诊结果

- `GET /api/v1/encounters`
- `GET /api/v1/encounters/{id}`

### 可选关联查询

- `GET /api/v1/recordings/{id}/encounters`
- `GET /api/v1/analysis/runs/{id}/encounters`

### 后续操作

- `POST /api/v1/encounters/{id}/actions/merge`
- `POST /api/v1/encounters/{id}/actions/split`
- `POST /api/v1/encounters/{id}/actions/confirm`

## 3. MVP 最小返回字段

### `encounter` 列表

- `id`
- `recording_id`
- `run_id`
- `tenant_id`
- `employee_id`
- `employee_name`
- `start_at`
- `end_at`
- `duration`
- `summary`
- `confidence`
- `status`

### `encounter` 详情

- `id`
- `recording_id`
- `run_id`
- `base_info`
- `segments`
- `transcript`
- `confidence`
- `status`
- `created_at`
- `updated_at`

## 4. 页面映射

- `医生录音列表` 调 `GET /api/v1/recordings` + `POST /api/v1/recordings/{id}/actions/reanalyze`
- `运行审计` 调 `GET /api/v1/analysis/runs`
- `就诊列表` 调 `GET /api/v1/encounters`
- `就诊详情` 调 `GET /api/v1/encounters/{id}`

## 5. 说明

- 本项目不允许前端直连大模型。
- 所有分析必须走现有录音分析链路。
- `encounter` 是这次 MVP 新增的业务结果对象，`recording` 仍然是输入素材。
