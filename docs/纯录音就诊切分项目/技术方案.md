# 纯录音就诊切分技术方案

## 目标

仅依赖录音，把连续门诊音频切分为一次次 `encounter`。

## 前提

- 不依赖挂号、叫号、排班等外部系统数据。
- 现有能力以阿里 `FunASR` 为基础。

## 总体思路

1. 先用 `FunASR` 得到语音识别结果、时间戳、静默切分。
2. 基于音频时序和文本语义做边界检测。
3. 输出 encounter 片段和置信度。
4. 低置信片段留给人工修正，反哺规则和模型。

## 最小可用架构

- `ASR`: 负责转写与时间戳。
- `VAD`: 负责切静默，缩小候选边界。
- `Boundary Engine`: 负责判定 encounter 起止。
- `Post Process`: 负责合并、拆分、去抖动。

## 边界特征

- 长静默。
- 说话人切换。
- 语义主题突变。
- 结束性话语，如“好了”“下一个”。
- 诊疗动作结束后的低活跃区间。

## 产出

- encounter 列表。
- 每段起止时间。
- 段内转写文本。
- 置信度。

## 落地策略

- 先离线切分。
- 再做班后人工修正。
- 最后再考虑近实时提示。

## 结论

`FunASR` 足够作为起点，不需要一上来再堆很多模型。真正要补的是一层 encounter 切分逻辑。
