# 二维码一键授权核验结论

## 官方文档证据

企业微信帮助文档 `doc_id=21677`（已归档为 `wecom-help-21677.html`）的正文步骤是：

1. 打开企业微信客户端，进入“工作台 → 智能机器人”；
2. 点击“创建机器人 → 手动创建”；
3. 选择“API 模式创建”；
4. 选择连接方式“使用长连接”；
5. 页面自动生成并展示 Bot ID 和 Secret；
6. 配置机器人可见范围并保存。

文档没有提供“第三方 SaaS 生成二维码 → 管理员扫码 → 自动创建智能机器人”的开放接口、OAuth 授权地址或回调协议。

## 确定结论

### 已确认可实现

- 灵策生成自己的二维码，让管理员扫码登录灵策或打开接入向导；
- 管理员扫码后进入企业微信官方机器人创建页面；
- 管理员手动创建 API 模式长连接机器人；
- 管理员把 Bot ID/Secret 填回灵策；
- 灵策自动校验凭证并建立长连接。

### 当前官方材料不能证明可实现

- 灵策二维码直接触发企业微信创建机器人；
- 扫码自动返回 Bot ID 和 Secret 给灵策；
- 灵策通过 OAuth 回调代替管理员完成机器人创建；
- 灵策通过二维码自动设置机器人可见范围。

## 对“豆包工作扫码创建”的解释

豆包工作里的二维码很可能是豆包自己的接入向导或服务绑定流程。仅凭它能生成二维码，不能推导出企业微信向第三方 SaaS 开放了同样的通用机器人创建授权接口。企业微信公开帮助文档目前仍把 API 模式机器人的创建描述为“手动创建”，并要求管理员在企业微信客户端内获取 Bot ID 和 Secret。

## 可落地的最简客户流程

1. 灵策生成一次性二维码，管理员扫码进入灵策接入页；
2. 灵策展示官方创建步骤和“打开企业微信创建机器人”按钮；
3. 管理员按官方步骤创建机器人并复制 Bot ID/Secret；
4. 回到灵策粘贴一次；
5. 灵策自动完成连接验证、测试消息和状态展示。

因此，二维码可以减少登录和导航成本，但目前不能据官方文档把它宣传成“扫码即自动完成企业微信机器人授权”。
