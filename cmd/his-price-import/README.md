# his-price-import

把「派特定价体系价目表」原始 CSV 清洗后导入 HIS 收费项目（`his_charge_items`），
只做**初始数据**，不做定价模板、不做倍率×城市系数、不导入材料。

## 用法

```bash
export LINGCE_DEV_DB_URL='postgres://.../lingce_dev?sslmode=disable'

# 1) 先 dry-run 看清洗结果与去重情况
go run ./cmd/his-price-import \
  -csv ../../lingce-data/医保收费字典/解析/20261029_定价体系_价目表_raw.csv \
  -tenant-id 1 -dry-run -report ../tmp/price-import-report.csv

# 2) 生成拼音表（可选，填充 pinyin/initials 供拼音检索）
python3 scripts/his_price_pinyin.py tmp/price-import-report.csv > tmp/price_pinyin.tsv

# 3) 正式导入（可重复执行）
go run ./cmd/his-price-import -pinyin-tsv tmp/price_pinyin.tsv -report tmp/price-import-report.csv
```

## 源表列顺序不规整，按「倍率列」定位

原始表头是 `项目,医保价,品类倍率,北京,深圳,成都,昆明,其他`，但每行字段数可变：

| 形态 | 示例 | 解析方式 |
| --- | --- | --- |
| 带分区标题前缀 | `诊费类<br>,妇科/中医初诊—知名专家,￥80,4x,￥300,…` | 倍率在第 m 列 → 项目名 m-2、医保价 m-1、北京 m+1 |
| 无分区标题 | `妇科/中医初诊—主任医师,￥60,3\.5x,￥200,…` | 同上，自动对齐 |
| 无项目名列（只有医保全名） | `经腹部妇科B超检查￥54,2x,￥108` | 项目名从医保价列去价后取 |
| 组套子项（说明行） | `梅毒螺旋体抗体\(抗TP\)测定 ￥30` | 宽松模式：首列为名，无北京价回落医保价 |
| 心理/陪诊区块（无倍率） | `陪诊服务/小时,￥100,￥50\-80,￥100,￥80` | 首列为名；北京价取第 2 个含￥列（优先带 Nx） |
| 纯说明长文本 | 第 128 行心理咨询多段报价 | 跳过并记录 |

分区标题（`诊费类`/`检验类`/`检查类`/`治疗类`/`中医针灸`/`中药贴敷`/`TCT+HPV` 等）作为上下文，
用于分类兜底，不作为收费项目；项目名为空或是标题时，改从医保价列取项目全名。

## 清洗规则

- 去 `<br>`/`<BR/>` 等标签、去 markdown `**`（单个 `*` 是乘号，保留）、反转义 `\.` `\-` `\(` 等
- 名称：压缩空白、去尾部 `/次`「/人次」、去尾部标点；全半角括号混用时统一为半角
- 价格：优先「北京」列 `￥xxx`；无北京价回落「医保价」列；去 `￥`/逗号/转义符；
  区间价（`￥50-80`、`￥1000-2000`）取低价并在报告标注；仍无价的行跳过
- 单位默认 `次`，代煎/煎药为 `剂`
- 分类：诊查 / 检验 / 检查 / 治疗 / 其他（关键词优先，分区上下文兜底）
- 去重：规范化名称（去空白/连字符、全角转半角、小写）比对既有项目；项目名与「医保全名」双键比对；
  医保全名再派生「去括号补充」「去尾缀 测定/试验/检查」两个键（识别既有库里的简写名），
  组套（`*项`/含 `+`）不做医保全名去重；源表内同名保留首条；`manualSkip` 列人工复核确认的同一项目
- 编码：`PRC0001` 起，跳过已占用序号；`status='active'`；`ON CONFLICT (tenant_id, code) DO NOTHING`
- 源表笔误：`CPP` → `CRP`（源表「C反应蛋白(CPP)测定」）

## 幂等

第二次执行：`本次新增 0 条`（136 条均判定为与既有项目重复），不会覆盖既有价格。
